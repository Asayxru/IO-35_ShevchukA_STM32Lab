# Підключення компонентів

## Таблиця пінів

| Пін STM32 | Режим / AF | Периферія | Сигнал | Напруга | Pull-up/down | Звідки взято |
|---|---|---|---|---|---|---|
| PA1 | ADC1_IN1 | ADC1 | Вихід потенціометра | 0–3.3 В | немає | `firmware.ioc`, `diagram.json` |
| PA2 | USART2_TX | USART2 | UART TX | 3.3 В | немає | `firmware.ioc` |
| PA3 | USART2_RX | USART2 | UART RX | 3.3 В | немає | `firmware.ioc` |
| PB0 | GPIO Input | GPIO | Кнопка | 3.3 В | внутрішній Pull-Up | `firmware.ioc`, `diagram.json` |
| PB6 | AF6 / GPIO | I2C1, software I2C | BMP180 SCL, Analyzer D0 | 3.3 В | Pull-Up при відпусканні | STM32 datasheet, `firmware.ioc` |
| PB7 | AF6 / GPIO | I2C1, software I2C | BMP180 SDA, Analyzer D1 | 3.3 В | Pull-Up при відпусканні | STM32 datasheet, `firmware.ioc` |

Кнопка підключена до землі, тому вона активна низьким рівнем. У відпущеному стані читається HIGH, а при натисканні — LOW.

## Адреси I2C

| Пристрій | 7-бітна адреса | Байт запису | Байт читання |
|---|---:|---:|---:|
| BMP180 | `0x77` | `0xEE` | `0xEF` |
| Адреса для перевірки NACK | `0x76` | `0xEC` | `0xED` |

## Регістри BMP180

| Регістр | Значення / призначення |
|---:|---|
| `0xD0` | CHIP_ID, очікується `0x55` |
| `0xAA–0xBF` | 22 байти калібрувальних даних |
| `0xF4` | регістр команд |
| `0x2E` | команда вимірювання температури |
| `0x34` | команда вимірювання тиску при OSS=0 |
| `0xF6–0xF8` | сирі результати вимірювання |

## Параметри шини

- Шина реалізована програмно через GPIO.
- У стані спокою SCL і SDA відпущені та мають HIGH.
- LOW створюється режимом `GPIO_MODE_OUTPUT_OD`.
- HIGH створюється режимом input pull-up.
- Logic Analyzer: D0 — SCL, D1 — SDA.
- Є обмежене очікування підняття SCL, після якого повертається timeout.
- У записаних VCD частота вийшла приблизно 209–278 Гц. Вона низька через затримку та часте перемикання режиму GPIO у Wokwi.

## Оцінка споживання

Це приблизна оцінка тільки для зовнішніх компонентів, без самої плати NUCLEO.

| Компонент | Приблизний струм |
|---|---:|
| BMP180 | близько 5 мкА при одному вимірюванні за секунду, до 650 мкА під час перетворення |
| Потенціометр 10 кОм | близько 330 мкА при 3.3 В |
| Кнопка | майже 0 у відпущеному стані |
| Logic Analyzer | у Wokwi фізично струм не споживає |

Разом виходить приблизно 0.34 мА у звичайному режимі та до 1 мА під час вимірювання BMP180. Для живлення від 3.3 В плати це невелике навантаження.

## Варіанти, які не використав

1. **Hardware I2C на PB6/PB7.** CHIP_ID і calibration іноді читалися, але при записі команди у `0xF4` Wokwi повертав помилку або timeout. Через це залишив software I2C.
2. **Перенесення I2C на інші піни.** Треба було б змінювати готову схему та заново перевіряти Wokwi. Робоча схема ЛР1 вже використовувала PB6/PB7.
3. **ADC на PA0 замість PA1.** Такий варіант можливий, але PA1 уже був налаштований у CubeMX і підключений у схемі.
