# PRD - Indoor Environmental Monitoring and Alert System

## A. Загальна ідея

Ідея проєкту - зробити просту систему моніторингу параметрів навколишнього середовища на STM32. Система буде зчитувати температуру і атмосферний тиск, аналоговий сигнал через ADC, стан кнопки або іншого цифрового датчика та виводити ці дані через UART.

У цій лабораторній ми перевіряємо базову частину такої системи. BMP180 використовується як I2C-сенсор температури і тиску, потенціометр використовується для перевірки ADC, а кнопка - для перевірки GPIO. У наступних лабораторних ці тестові компоненти можна буде замінити реальними датчиками.

## B. Функціональні вимоги

- **FR-01:** система повинна вимірювати температуру через I2C-сенсор.
- **FR-02:** система повинна вимірювати атмосферний тиск через I2C-сенсор.
- **FR-03:** система повинна зчитувати аналоговий сигнал через ADC.
- **FR-04:** система повинна зчитувати стан цифрового входу GPIO.
- **FR-05:** система повинна виводити дані та повідомлення через UART на швидкості 115200 бод.
- **FR-06:** система повинна оновлювати дані приблизно раз на секунду.
- **FR-07:** якщо I2C-сенсор не відповідає, система повинна показати помилку.
- **FR-08:** I2C-обмін повинен бути видно на Logic Analyzer.
- **FR-09:** у Wokwi користувач повинен мати можливість змінювати значення компонентів і бачити зміни в UART.
- **FR-10:** прошивка повинна збиратися в Docker через ARM GCC toolchain.

## C. Сенсори та компоненти

### 1. BMP180

- **Інтерфейс:** I2C.
- **Адреса:** `0x77`.
- **Для чого використовується:** вимірювання температури і атмосферного тиску.
- **Виконує вимоги:** FR-01, FR-02, FR-07, FR-08, FR-09.
- **Чому обраний:** у Wokwi є готовий компонент, і через нього можна нормально перевірити роботу I2C, регістрів і Logic Analyzer.
- **Альтернативи:** BME280, MPU6050. BME280 має більше можливостей, але для цієї лабораторної BMP180 простіший. MPU6050 вимірює інші параметри і в нашому випадку працював нестабільно.

### 2. Потенціометр

- **Інтерфейс:** ADC.
- **Пін:** `PA1 / ADC1_IN1`.
- **Для чого використовується:** перевірка аналогового входу.
- **Виконує вимоги:** FR-03, FR-09.
- **Чому обраний:** значення легко змінювати прямо під час симуляції.
- **Можливі альтернативи:** фоторезистор, MQ-2, MQ-135 або інший аналоговий датчик.

### 3. Кнопка

- **Інтерфейс:** GPIO.
- **Пін:** `PB0`.
- **Режим:** Input Pull-Up.
- **Для чого використовується:** перевірка цифрового входу.
- **Виконує вимоги:** FR-04, FR-09.
- **Можливі альтернативи:** PIR-датчик, геркон, кінцевий вимикач.

## D. План тестування

| Вимога | Як перевіряємо | Очікуваний результат |
|---|---|---|
| FR-01 | Змінити temperature BMP180 у Wokwi | У UART змінюється `temp` |
| FR-02 | Змінити pressure BMP180 у Wokwi | У UART змінюється `pressure` |
| FR-03 | Покрутити потенціометр | Значення ADC змінюється приблизно від 0 до 4095 |
| FR-04 | Натиснути і відпустити кнопку | `button=released` змінюється на `button=PRESSED` |
| FR-05 | Запустити симуляцію | UART стабільно виводить дані |
| FR-06 | Подивитися на `tick` | Новий рядок з'являється приблизно раз на 1000 ms |
| FR-07 | Від'єднати BMP180 | У UART з'являється повідомлення про помилку |
| FR-08 | Записати VCD і відкрити в PulseView | Видно SCL, SDA, адресу `0x77` і ACK |
| FR-09 | Змінити всі компоненти | UART показує відповідні зміни |
| FR-10 | Запустити build у Docker | Проєкт збирається без помилок |

## Результат ЛР1

ЛР1 можна вважати виконаною, якщо проєкт збирається в Docker, запускається у Wokwi, UART працює, BMP180 читається по I2C, ADC і GPIO реагують на зміни, а I2C-трафік видно на Logic Analyzer.
