# Перевірка I2C через Logic Analyzer

У цій папці знаходяться три VCD, які я записав під час реального запуску Wokwi. Скрипт `scripts/decode_i2c_vcd.py` їх не створює, а тільки читає переходи SCL/SDA та показує байти.

## 1. Читання CHIP_ID

Файл: `i2c_bmp180_chip_id.vcd`.

Результат декодування:

```text
118.192 ms START
160.063 ms ADDRESS 0x77 WRITE ACK
201.966 ms DATA 0xD0 ACK
206.754 ms START
248.616 ms ADDRESS 0x77 READ ACK
282.166 ms DATA 0x55 NACK
289.345 ms STOP
```

Спочатку STM32 передав адресу `0x77` у режимі запису та номер регістра `0xD0`. Після повторного START адреса була передана в режимі читання. BMP180 повернув правильний CHIP_ID `0x55`. Після останнього байта master передав NACK і завершив обмін.

Середня за медіаною частота SCL у цьому записі — приблизно `209.1 Гц`.

## 2. Калібрування та вимірювання

Файл: `i2c_bmp180_measurement.vcd`.

Основні байти з запису:

```text
CHIP_ID:       77/W D0 77/R 55
Calibration:   77/W AA 77/R
               01 98 FF B8 C7 D1 7F E5 7F F5 5A 71
               18 2E 00 04 80 00 DD F9 0B 34
Temperature:   77/W F4 2E
Raw UT:        77/W F6 77/R 86 89
Pressure:      77/W F4 34
Raw UP:        77/W F6 77/R 40 C2 00
```

Калібрувальний блок має 22 байти. Перед читанням температури у `0xF4` записано `0x2E`, а перед читанням тиску — `0x34`. Сирі значення з VCD дають `+62.7 °C` та `53500 Pa`, що збіглося з UART у Wokwi.

Усі проміжні байти читання підтверджені ACK. Останні байти UT, UP і calibration завершуються NACK. Частота SCL у цьому довшому записі — приблизно `278.0 Гц`.

## 3. Перевірка NACK

Файл: `i2c_bmp180_nack.vcd`.

```text
118.187 ms START
160.068 ms ADDRESS 0x76 WRITE NACK
166.062 ms STOP
```

Адреса `0x76` у схемі не використовується. Після адресного байта отримано NACK, тому передача регістра не продовжувалась і STM32 сформував STOP. Частота SCL — приблизно `209.1 Гц`.

## Як я переглядав записи

У PulseView потрібно додати I2C decoder і вибрати:

- SCL — D0/PB6;
- SDA — D1/PB7;
- формат адреси — 7 bit.

Для швидкої текстової перевірки використовував команду:

```sh
python scripts/decode_i2c_vcd.py docs/captures/ім'я_файлу.vcd
```

Усі три потрібні варіанти — CHIP_ID, measurement і NACK — записані та перевірені.
